# PWA Icons for Kayan Dashboard

This directory should contain the following icon files for PWA support:

- icon-16x16.png
- icon-32x32.png
- icon-72x72.png
- icon-96x96.png
- icon-128x128.png
- icon-144x144.png
- icon-152x152.png
- icon-192x192.png
- icon-384x384.png
- icon-512x512.png

## Generate Icons

1. Open `generate-icons.html` in a browser
2. Icons will be generated automatically
3. Download the icons and place them in this directory

## Alternative: Use Online Tool

You can also use online PWA icon generators:
- https://realfavicongenerator.net/
- https://www.pwabuilder.com/imageGenerator

Use the brand colors:
- Primary: #ec4899 (Pink)
- Secondary: #14b8a6 (Teal)
- Background: White

## Quick Setup

For now, you can use a simple colored square or the favicon.ico as a placeholder until proper icons are created.
